# Contributing

This repository is **maintained solely by InventDB**. It is published so you can read,
use and fork it — not as a collaborative project.

**We do not accept external pull requests.** Any PR opened from outside the InventDB
organisation will be closed without review. This is not a judgement on the change; we
simply keep this codebase under single-maintainer control.

## What to do instead

**Want to change how it behaves?** Fork it. The [MIT licence](LICENSE) lets you use,
modify and redistribute the code, commercially or otherwise. Keep the copyright notice
and you are free to take it wherever you need.

**Found a bug, or something in the documentation is wrong?** Open an issue. We read
them, and a clear report is genuinely useful even though we will write the fix
ourselves. Please include your Claude Code version, your operating system, and the
relevant lines from `~/.claude/inventdb-sync/state/sync.log`.

**Never include credentials, tokens, or raw session content in an issue** — session
logs capture whatever was on screen, which routinely includes secrets.

## Security

Do not report security issues in a public issue. Email security@inventdb.com instead.
